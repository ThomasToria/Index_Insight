# Archive

Ce dossier contient des artefacts déplacés de l'arborescence active sans suppression. Ils sont conservés pour pouvoir retracer les traitements historiques, mais ne doivent pas être interprétés comme des fiches de la base principale.

`llm_database_non_record_artifacts/` contient notamment des fichiers agrégés, de diagnostic ou d'erreurs qui étaient placés parmi les JSON individuels de `LLM_Tagged_Database/`.
